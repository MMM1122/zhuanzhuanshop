# Zhuanzhuan Shop (转转小店)

An interactive, web-based digital spinner and shop interface designed to turn selections, rewards, or items into an engaging spin-and-win experience.

## Overview

Zhuanzhuan Shop combines a playful lucky wheel (转转乐 / 转盘) mechanism with a lightweight storefront display. Users can trigger random draws, browse featured items, and interact with the storefront directly in the browser.

## Features

- **Interactive Lucky Wheel**: Smooth CSS/JS spin animations with customizable reward segments and probabilities.
- **Item Showcase**: Clean, organized catalog display for featured products or prizes.
- **Zero Dependencies**: Built with pure HTML, CSS, and vanilla JavaScript for ultra-fast load times and seamless hosting via GitHub Pages.
- **Responsive Layout**: Optimized for both mobile taps and desktop clicks.
